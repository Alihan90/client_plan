# Client Planner (Flutter)

Простой кроссплатформенный планер записей клиентов/пациентов для iOS и Android со статусами выполнения и виджетом на главный экран.

## Возможности
- **Управление записями:** создание, редактирование и удаление (имя, услуга/заметка, дата, время).
- **Статусы записей с цветовой индикацией:**
  - **Серый** — режим ожидания (пока запись не отмечена).
  - **Зелёный** — выполнено (отмечается кнопкой галочки в списке или при редактировании).
  - **Красный** — не выполнено (отмечается кнопкой крестика в списке или при редактировании).
- **Дублирование для постоянных клиентов:** при создании записи можно продублировать её на выбранные дни недели до конца месяца.
- **Режимы просмотра:** **День** (список по времени), **Неделя**, **Месяц** (сетка календаря с шапкой дней недели и кнопкой «Назад»).
- **Синхронизация с виджетом:** отправка списка записей и их статусов на виджет рабочего стола через `home_widget`.
